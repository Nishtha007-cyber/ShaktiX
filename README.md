ShaktiX: a Safety Alert App

The app addresses emergency communication gaps by enabling automated SOS activation, real-time tracking, 
and multi-channel alerting for faster response and enhanced personal safety.

Importance of a Safety Alert App:
1) Instant Emergency Communication
2) Hands-Free Activation
3) Real-Time Location Sharing
4) Improved Personal Confidence
   
Application Features:
1) Emergency Triggers: Shake detection triggers an SOS and sends an SMS with a Google Maps link to the user’s location.
2) Emergency Contacts: Users can place emergency calls and save emergency contacts.

Programming Language: Kotlin
Sensors used: Accelerometer sensor
SharedPreferences are used to save contact names and numbers.
Gesture Detection Logic: threshold-based detection
Countdown: Handler.postDelayed() delays the countdown by five seconds.


   *This is a prototype of the safety app
